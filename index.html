Featured projects

ML Infrastructure Trojans · CCS 2026

(A)iSpy

Parasitic Trojans for Machine Learning Infrastructure

ML pipelines audit data and model artifacts, but the execution environment underneath them is trusted implicitly. (A)iSpy exploits that blind spot: a parasitic infrastructure Trojan that registers as an ordinary runtime extension and subverts training and inference through an active observe-and-execute paradigm. Living inside the computation graph, it watches transient tensor state and performs targeted manipulations at negligible overhead. Against confidentiality, it recovers the critical training hyperparameters and covertly exfiltrates them through model weights or output logits. Against integrity, it acts as a gradient amplifier, converting otherwise ineffective data poisoning into a working backdoor once a steganographic trigger appears. Subpopulation label flipping, availability disruption, and inference-stage manipulation are demonstrated as further attacks. Evaluated malware scanners do not flag it, since public rule sets have no coverage for ML runtime Trojans, and the poisoned inputs and compromised models slip past state-of-the-art inspection tools. Implemented in the ONNX Runtime training and inference engines.

Backdoor ASR ~0% → 100% Hyperparameter exfiltration Undetected by malware scanners ONNX Runtime + TensorRT

Runtime Attack Detection

SAMURAI

Safeguarding Against Malicious Usage and Resilience of AI

AI accelerators are increasingly vulnerable to adversarial evasion attacks, where small, imperceptible perturbations to input data lead to incorrect model predictions. SAMURAI is a framework for runtime attack detection in AI accelerators, featuring an array of AI Performance Counters (APCs) that monitor the dynamic behavior of AI models - much like Hardware Performance Counters track activity in modern microprocessors. A lightweight on-chip ML engine called TANTO (Trained Anomaly Inspection through Trace Observation) concurrently analyzes APC traces to detect threats during inference. Evaluated on image and audio inputs (including 2D Mel-spectrograms) across multiple CNN architectures.

98% detection accuracy < 3% energy overhead < 4% area overhead < 10% latency

Adversarial ML · CVPR 2026

DASH

A Differentiable Meta-Attack Framework for Perceptually-Aligned Adversarial Examples

Norm-bounded adversarial examples (ℓp-constrained) often fail to align with human perception. DASH is a differentiable meta-attack framework that strategically composes existing ℓp-based attacks to generate effective and perceptually-aligned adversarial examples. Operating in a multi-stage fashion, DASH aggregates candidates from multiple base attacks using learned, adaptive weights and propagates the result forward. A novel meta-loss jointly minimizes misclassification loss and perceptual distortion, dynamically modulating each base attack's contribution. Evaluated on adversarially trained robust models across CIFAR-10/100 and ImageNet.

+20.63% ASR vs AdvAD SSIM +11 LPIPS +0.015 FID +5.7

Model Compression · IEEE TCOMP

WINGS

Automatic Weight Generator for Storage-Efficient Deep Learning Models

Storing millions of synaptic weights is the main barrier to running large models on edge hardware. WINGS removes that cost by generating weights at inference time instead of storing them. A gradient-based sensitivity analysis ranks layers; low-sensitivity layers are compressed with PCA, and lightweight support vector regression models predict each layer's reduced components from the previous layer, so only PCA bases, the first compressed layer, the SVR predictors, and the untouched high-sensitivity weights are kept. Nothing is retrained. The same structure yields tamper evidence for free: a bit-flip in a stored coefficient perturbs an entire weight row along a dominant principal direction, so the accuracy drop is amplified and the attack becomes observable at a fraction of the redundancy cost of ECC. Validated on CNNs and on transformer NLP models, with FPGA and 28nm ASIC measurements.

53x compression, FC layers 14x AlexNet · 11x ResNet-50 < 1% accuracy loss No retraining
